# RouteWise — Sales Supervisor Journey Planner

A journey-plan manager for sales unit managers. They plan weekly supervisor visits to markets, assign KPI tasks, follow live check-ins and review performance. It's a static single-page demo with no build step, running on mock JSON data.

## Features
- **Overview:** plan status, visit completion, KPI leaderboard and today's schedule.
- **Journey plans:** list and detail view with a weekly visit grid. Admins can add, reorder and remove stops.
- **Markets:** a map plus a searchable table of customer outlets.
- **Supervisors and routes:** coverage and health per route.
- **Live visits:** check-in status board and timeline.
- **Reports:** charts with period comparison and CSV export.
- **KPI tasks:** tasks that supervisors complete during visits.
- **Data model:** the entity-relationship diagram, rendered with Mermaid.

## Run

```bash
npx serve .
# open http://localhost:3000/login.html
```

Use localhost or https, because the login uses the browser's WebCrypto API. The mock data is generated by `tools/gen-mock-data.mjs`, and `tools/build-data-bundle.mjs` rebuilds the offline bundle.

## Demo access
There are two roles: `admin` (can edit plans, which are saved in the browser) and `viewer` (read-only). Ask the project owner for the credentials.

> With no backend, the login is a demo access gate rather than production security.

## Tech
HTML · vanilla JavaScript (hash routing) · Tailwind CSS · DaisyUI · Chart.js · Leaflet · Mermaid · Content-Security-Policy with SRI-pinned CDNs · PBKDF2-hashed credentials (WebCrypto)
